## A0：先审计调用，再宣布冻结

每条调用包含稳定 ID、组/libc、所在脚本和位置、展开序号、实际 argv、工作目录、环境、二进制/脚本/数据身份、依赖、前置与清理、预期边界和分片。结果名到调用 ID 的映射由 CRITERIA 维护，不能从 judge 类名、最终字典或日志出现次数倒推调用集合。

审计同时交付镜像枚举工具、源码/镜像 SHA256、提取命令、逐调用表和差异表。差异表逐项解释“脚本存在但 judge 没有”“judge 存在但脚本没有”“同名计划重复”“不同 libc 不同集合”。BusyBox 尚未闭合的脚本/判据差异必须在这里解决；#46 所列 6514/24、2820/2840 仅是候选数据，不能直接复制为已冻结事实。排除项须事先审阅并列出范围影响。

父脚本调用、覆盖项、动态断言分别计数。稳定 ID 可含父调用与子项序号，但必须给出实际输入到子项的可审映射；不能把 427 个 judge 键宣称为 427 次独立程序调用。计划重复不能靠放宽重复阈值处理。若原日志不能区分两个同名调用，记录 AMBIGUOUS_INVOCATION 并阻断；新增边界标记需另发 PROFILE revision，旧日志不补造身份。

每个组进入实现前，先提交该组的语法表：固定来源位置、原始正例、必需字段/单位、上下文、允许记录次数、错误例及预期规范结果。全套 A 完成需要全部组审计闭合；可先审小组子集，不把未审计部分标成 FROZEN。

## 唯一的数据通路

```text
原始私有字节 → Record[] → 组/调用/汇总状态机 → AnalysisResult
                                                   ├─ 逐项判断
                                                   ├─ 指标与诊断
                                                   └─ 验收与 JSON/Markdown
原始私有字节 → 冻结历史 judge → reference_observation（只对照）
```

接口以数据契约定义，不强制文件名：

- `Record`：稳定 record_id、原日志字节区间、从 1 起的行号、原始字节、识别文本、角色及结构字段。原字节不覆盖；解码错误可显示转义，不能忽略坏字节再识别成功。
- `Assignment`：每记录恰有一个归属结果：组边界、调用边界、调用结果、汇总头/字段、指标、允许信息或错误。结构归属含 group/libc/invocation/attempt ID、消费规则 ID；不能仅写 consumed=true。信息归属也要有规则 ID 和所属范围。
- `InvocationResult`：稳定调用 ID、每次尝试、结束状态、原生计数、结构化 diagnostics、结果证据 ID、指标及 judgment。保留所有尝试，不用名称字典覆盖，不用集合消除重复。
- `AnalysisResult`：固定 selection、全部记录/归属、逐调用结果、范围级错误与指标。构造结束后只读。判分、验收及渲染只消费它，不重新解析字符串、不修改它来凑通过。

证据引用是记录身份和字段值的引用，不是另一套解析器生成的 proof。某条记录可为同一调用的判断和指标同时提供证据，但只能有一个语义 owner；不能被两个调用或两次尝试借用。共享表头归属组上下文，指标引用其 ID，不能冒充额外成功事件。最终校验检查引用存在、角色匹配、归属唯一、记录无遗漏，不用第二套正则再次证明成功。

旧官方/团队 judge 原样锁定，输出只在 `reference_observation` 保存原始计数、输入哈希、实现身份及差异。不得作为最终 judgment 的输入，不能通过新 proof 修补旧 adapter 的 PASS。需要支持 basic 等组时，必须先把对应语义写进该组语法表和规范判据；未迁移的组明确拒绝为 UNSUPPORTED_GROUP（输入退出 2），不能回退调用旧 judge 判 PASS。对照工具超时、崩溃或非法输出记录独立 `reference_error`；不改变规范判断，但该轮对照验收不完成，不得声称历史校准通过。

## 字节与上下文规则

仅 LF 分记录；CRLF 的尾 CR 可用于识别时去掉，孤立 CR、VT、FF、NBSP、Unicode 行分隔不当空白或新行。结构内只允许 ASCII SP/HT；规则须锚定整条记录，不跨 LF 拼接。ANSI 只允许经语法表枚举的 SGR 颜色序列在识别副本中移除，并保留原位置映射；其他控制序列不用于构造成功结构。不能各组分别 strip/splitlines/去 ANSI。

先识别完整外层结构，再分类消息：`TINFO: quotes TPASS: text` 是一个信息事件，消息里的标志、组标记或 Summary 不递归解释。词法须识别合法结构和已登记保留前缀的损坏结构；非法分隔符不能把结构降成普通信息。组语法表必须定义保留前缀及合法结构所涵盖的语言，覆盖旧 adapter 曾接受的非规范变体。无法识别的普通诊断保留为 opaque 信息，不承诺识别任意伪造自然语言；缺少明确正向证据仍不能通过。

所有结构类型在全日志上识别一次，再按当前组判归属。组外、错 libc、错组和调用外的结果/汇总/指标都是带位置的错误。不能先切成功段而丢弃前后记录。匿名数字只在已登记的表格状态中解释；未知表头、非法行、中断或新上下文关闭旧状态，后续数字不得借用旧标签。

| 状态 | 合法转换 | 非法输入的确定行为 |
| --- | --- | --- |
| 组空闲/活动 | START → 当前组 → 同组 END | 重复/嵌套/错配记 ERROR；保留原活动组，错误标记不创建或关闭它；EOF 未闭合记 TRUNCATED |
| 调用空闲/活动 | 明确开始 → 当前调用 → 匹配结束 | 孤立结果/结束报错；嵌套开始不替换当前调用；重复调用另留尝试并永久阻断 |
| 单行结果组 | 一条完整结果对应一个可唯一识别的调用 | 无名、未知名、计划重复无法区分、重复结果均阻断，不按顺序猜测 |
| 汇总空闲/现代活动 | Summary → 五个唯一字段 → 完成 | 无头字段、重复字段/块、缺字段、混用旧式均报错；错误不能被后来的合法块清除 |
| 指标上下文 | 已知标签/trace/表头 → 完整数值行 | 孤立、跨错误上下文、非法值/单位报错；不发布为有效指标 |

恢复只为继续诊断，不修复已记录错误；不重绑错误记录。组正常闭合时仍有未闭合调用/汇总，一并记不完整后清空该组上下文；后续组可单独分析，整份报告仍 BLOCKED。状态码由枚举决定，不从错误文案中查找子串。JSON 与 Markdown 均展示位置、错误码、原值、单位和表格维度；格式转义不能改变身份。

## LTP 汇总与判定

A0 按冻结源码和真实日志列出支持的原生前缀、退出位及汇总格式，禁止猜测全部 LTP 输出都相同。现代汇总为 passed/failed/broken/skipped/warnings 五个唯一非负整数字段；一次调用最多一个块。旧式以 `Total Tests` 开始，后接唯一 Passed/Failed/Not Supported，核对总数及原生事件映射；映射不足的格式不支持，不能把未表达的 TBROK/TWARN 默认为 0。

字段只能在相应活动汇总中消费，不能因位于 invocation 区间就视为已校验。已出现的块必须完整且与原生结果一致；无论判据是否允许没有汇总，孤立/冲突字段都阻断。是否必须有汇总由 CRITERIA 按调用列明，不保留一个可以宽松兜底的全局 J1 开关。TINFO/TDEBUG 不计成功；TPASS/TFAIL/TBROK/TCONF/TWARN 保留记录数及冻结语义下的计数，事件与汇总分别列示，不相加。

规范结果 PASS 必须有完整且唯一的调用、所需合法正向证据和合法值，并满足[阶段契约](test001-redesign.md)的退出码、前置/清理和 LTP 条件。被测失败、跳过、警告、超时留在结果事实中；语法/归属冲突记 JUDGE_ERROR，缺结果 MISSING，未开始 NOT_RUN。并存事实全部保留，不让 judgment 单字段抹掉失败原因。所有解析错误、未知项、歧义及未归属结构都阻断验收；无观测不等于无错误。

| 测试族 | 成对正例/反例与断言 |

期望值由人工审阅的小型固定样本给出，不调用生产词法或验收函数生成预期。历史 judge 一致只是对照，已知错误允许纠正并说明差异。性质测试要求：添加失败、重复、孤立字段不能把 BLOCKED 提升为 PASS；改变信息消息不产生新结果；LF/CRLF 仅改变字节位置、不改变语义；诊断文案变化不影响状态。
