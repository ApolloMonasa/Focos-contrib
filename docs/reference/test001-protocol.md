# TEST-001 日志协议与验收不变量

关联：TEST-001 / #8 / #46。本文约束 A 阶段解析；不是新采集成绩。原始串口是证据，官方 judge 是观察来源，均不能单独决定验收。

## 一次解析，按范围消费

记录按 LF 分隔，CRLF 的 CR 仅作为行尾空白识别；VT/FF/Unicode 分隔符仍是消息正文，不能生成新记录。原始日志逐行生成结构事件：`line`（原日志从 1 起）、`raw`（未改写正文）、`text`（仅供识别的去 ANSI 文本）、`kind`、字段及允许的组。每行至多一个结构角色，消息正文不递归解释。组切分、调用状态机、观测守卫和性能提取复用同一批事件；官方 judge 读取该段正文，仅将 CRLF 行终止符归一化为 LF；事件 raw 和来源字节仍原样保留。

LTP 结果只接受三种前缀：`TPASS: message`、`file.c:123: TPASS: message`、`tag 1 TPASS : message`。已知或未知的 `T...` 标志只读结构字段；`TINFO: quotes TPASS: text` 仅为 TINFO。未经冻结的格式不猜测为成功。组标记、RUN/结束、Summary/汇总字段、非 LTP 标记/性能格式也统一识别；模糊标记保留并报错。格式扩展须修改协议及正反例。

每个事件的原日志行号不因切段、非法标记、跨组结果或过滤而改变。段内位置另列；报告指标和错误引用原日志位置。异常输入即使 BLOCKED，也必须可回查原始证据。

## 状态与基数

| 层 | 允许转移 | 错误行为 |
| --- | --- | --- |
| 组 | 空闲 → START → 活动 → 同名 END → 空闲 | 嵌套、重复、错配、非法标记和未闭合均阻断；异常行保留 |
| basic/libctest 调用 | START → 正文/结果 → 同名 END | 结果须属于当前调用；重复尝试、重复 Pass!、缺结束及模糊边界阻断 |
| LTP 调用 | RUN → 事件/可选汇总 → 同名退出记录 | 未知调用、重试、错配、非法退出、缺结束和未知标志阻断 |
| LTP 汇总 | 每尝试零或一个现代 Summary，或一个旧式汇总 | 重复块/字段、混合格式报 JUDGE_ERROR；重复块保留供诊断，但不能重复累加计数 |

现代汇总有 passed/failed/broken/skipped/warnings 五字段。J1 可缺汇总，J2 必须完整；已有汇总的矛盾对两者均阻断。原始事件与汇总分开统计。只有一条合法汇总可参与汇总计数，不能由重复记录增加成功数。消息引用的标志不能增加计数。

结构结果位于组外或与活动组不相容时记录原位置并阻断；未知/额外项不得丢弃或改变冻结分母。团队标记按实际组名匹配；性能标签、trace、表头的识别规则与性能提取共用。

## 身份与测试门槛

公开入口无条件建立私有源码/配置快照，随后从快照中的独立子入口执行。环境变量、普通参数不能跳过该步骤；分析实现身份描述实际执行副本。

先验证格式样本，再按“位置 × 事件角色 × 基数 × 结束状态”做组合负例。必须满足：引用文本不产出结果；增加失败/重复不能提高验收；J1/J2 使用同一采集身份与分母；全部事件可定位回原行；外部日志不能验收通过。已完成协议错误检查不允许删除异常证据行。新增格式及规则变化同时复核 15 份历史结果与真实 LTP 样本，差异明确解释。
