# 实验记录速查

入门步骤见 [性能实验](../benchmarks.md)。当前无实测成绩。

## 对照设置

B0：正确 FAT32 写穿，无块缓存。B1：固定预算普通块缓存，仍写穿。候选策略在 B1 上逐项开关；写回依赖块缓存，不构造不可能的组合。比较策略固定布局，比较布局固定策略。

## 一次运行的记录

| 类别 | 必记内容 |
| --- | --- |
| 版本 | run ID、时间、内核/测试 SHA、Rust/链接器/参数 |
| 设备 | 板型号、固件、频率/核数、内存限制、介质与控制器模式 |
| 数据 | 镜像/数据 SHA256、分区、FAT 簇大小、初始状态 |
| 负载 | 请求大小、数量、并发、种子、缓存总预算与分配 |
| 测量 | 预热、清了哪层缓存、计时边界、逐轮结果/失败 |

每轮恢复相同状态。冷缓存须说明应用/内核/设备哪层可控。交错或随机顺序跑至少 7 轮，报告中位数和 IQR；尾延迟建议每轮至少 1000 个请求。同轮请求不能冒充独立实验轮次。

## 写入与检索的特殊要求

写回分别报告调用返回、flush、全部承诺工作完成的时间；同步后重启校验，注入写失败，保留脏块。设备无有效 flush 时说明保证范围，不声称断电持久化或 FAT32 任意断电原子性。

HNSW 轨迹回放保存真实搜索的节点序列及文件偏移映射，只测存储。真实查询另记录数据集、维度、距离函数、M、efConstruction、efSearch、k、查询与精确近邻结果。索引须按需读盘；预算包括应用、索引常驻区、内核缓存和临时空间。

查询比较固定召回率与总内存，同时测 CPU 与 I/O 等待。跨板分别对照各自基线；介质差异不能解释成 CPU 架构收益。
