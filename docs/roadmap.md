# 区域赛：做成能用的内核

2026-11-06 调整：区域赛从“基础文件闭环”提高到 **2025 初赛除 LTP 全部通过 + vim/gcc/make 可用**。准确验收边界只维护在 [REGION-001](../specs/REGION-001.md)。

## 最终演示

VisionFive2 启动 → vim 编写 C 程序 → make 调用 gcc 编译、链接 → 运行新程序 → 保存文件并同步 → 重启读回。随后展示 QEMU 的完整测例结果和真板 FAT32 缓存对照。

FAT32 是基础与研究对象；Ext4 用于历史原版镜像。动态链接、线程、信号、mmap、管道、终端和网络兼容都进入区域赛范围，不能继续列为全国赛以后再做。

## 多平台怎样推进

区域赛先验证“同架构换板”，全国赛再验证“跨架构复用”。架构设计见 [分层图](architecture.md)，各环境独立保留结果；下面是验收计划，尚不是通过记录。

| 顺序与环境 | 先补什么 | 该环境的验收门槛 |
| --- | --- | --- |
| 1. QEMU RISC-V | 将固定机器配置归入板级边界；接入 CPU 与驱动接口 | 启动、内存、异常/时钟、任务、块设备；完整兼容目标仍按 REGION-001 |
| 2. VisionFive2 | 固件入口、RAM/保留区、设备时钟/复位、UART/SD 和 DMA 能力 | 冷启动、自有设备读写、用户态、文件同步重启；工具与性能按 REGION-001 |
| 3. QEMU LoongArch | 第二套页表/上下文/ABI；按机器配置接入中断控制器和存储传输 | 独立构建启动、用户隔离、任务与 ABI、同一套文件系统行为回归 |
| 4. 星云 2K1000LA | 实板固件、内存、控制器及连接信息逐项核对 | 同类 CPU/设备冒烟与真板文件闭环；再推进全国赛兼容与性能目标 |

1 与 2 可按模块并行推进；3 先复用公共内核，4 再补板级与驱动差异，不能从 QEMU 成功推定真板支持。星云板的启动协议、存储控制器、DMA 一致性与固件版本须由 #11 调查后锁定，当前不预设它与 QEMU 相同。

每个平台依次提交：资源清单与 SPEC → 最小启动/内存 → 时钟/异常/上下文 → 设备 → 用户态和存储回归。每步先写失败测试，再实现；不为尚未接入的平台设置必过 CI。已有目标继续回归，新目标能构建和运行后再加入 CI；板上日志独立归档。

设计审查检查三个替换场景：换同架构板型只补板级/设备差异；换 CPU 只补架构/ABI 及机器资源；换存储控制器保留 BlockDevice 与 FS/VFS。若公共策略必须识别板名，先修改边界 SPEC 再继续。

## 日期是检查点，不是已验证工期

当前只有启动基础，尚无兼容性运行成绩。3 人每周各 10–14 小时；从 11/6 到 12/20，按均匀投入粗估约 193–270 人时，留 25% 给审阅、集成与材料后，约 145–203 人时可用于实现。新范围在这一预算内属高风险，尚未证明可按期完成。

| 检查点 | 要拿出的证据 | 落后时怎么处理 |
| --- | --- | --- |
| 11/8 | 每项必达有 owner；镜像/ABI 调查；三份 3–6 小时交付 | 先拆任务和明确依赖 |
| 11/15 | SD 读写；FAT32 host 解析；2025 镜像与子用例清单；兼容工作估时 | 结对处理阻塞，重估剩余工时 |
| 11/29 | 文件闭环、Ext4、shell/basic，给出 11 组差距表 | 明确报告计划偏差，停止 HNSW 和额外优化 |
| 12/6 | 完整测试扫描、vim/gcc/make 首次闭环 | 集中修阻塞；不把“全部”改成“选定子集” |
| 12/13 | 必达回归与缓存数据，功能冻结目标 | 如仍未达标，列出缺项并与负责人决定投入/交付调整 |

缩减范围必须显式修改 REGION-001 并经负责人确认；不能删掉失败用例使通过率好看。截止日期依据见 [来源](references.md)。

## 研究主线与全国赛

AI 记忆检索是应用动机：索引放不进内存时，文件访问是否成为瓶颈？区域赛先用正确系统与缓存数据回答存储问题；普通 LRU 是对照，不直接称为算法创新。

必达稳定后可回放真实 HNSW 节点访问轨迹，回放耗时不叫查询延迟。全国赛推进 LoongArch/星云板、当届兼容与 LTP、2026 CAgent/BuildStorm 参考任务，以及真实按需读盘的 HNSW 查询；同召回率、同总内存预算比较两板各自的收益。
