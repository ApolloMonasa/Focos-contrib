# 怎样做第一组性能图

当前没有文件系统实测数据。先通过功能验收，再比较速度。

## 第一轮只比较缓存开关

1. 冻结正确的 FAT32 写穿基线 B0：写入继续交给底层设备。
2. 加固定容量块缓存 B1，仍然写穿。
3. 在 VF2 上固定镜像、请求序列和内存预算，交错跑至少 7 轮。
4. 同时画延迟、物理 I/O 和内存成本，解释收益与退化。

先做热点随机读、均匀随机读和顺序读。只与无缓存相比能证明缓存有效；新策略还应与普通缓存 B1 比。

## 有证据后再加策略

| 发现的瓶颈 | 候选策略 | 额外检查 |
| --- | --- | --- |
| 重复路径查找 | 目录缓存 | 增删后失效正确 |
| 碎片文件定位慢 | FAT 簇链缓存 | 元数据读取与内存成本 |
| 小写请求过多 | 写回/合并 | flush、失败脏块保留、同步重启 |

每次只改变一项，保持总预算。写回计时必须含最终同步；只读查询不能证明写回收益。

## 留哪些证据

保留 SHA、设备/固件、镜像、负载和随机种子、预算、预热/清缓存方式、计时范围、每轮结果。图表由脚本生成，标单位、样本数和波动；计时期间关闭逐请求串口输出。

2025 测例用于兼容验收，其耗时与 FAT32 消融分开报告。HNSW 回放是可选存储负载，真实查询和双板比较在全国赛推进。参数与图表清单见 [实验细则](reference/experiment-protocol.md)。
