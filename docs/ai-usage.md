# FocOS AI 辅助开发记录

## 2026 年 11 月 4 日初始化

工具：Codex。模型家族由会话环境标识为 GPT-6；具体子型号/配置未提供可核验元数据，需随会话导出补充，不猜测填写。

使用范围：读取本地赛规，审计历史测试分支，形成路线、协作要求与性能实验设计；创建并转移私有仓库；编写 BOOT-001、最小 Rust 裸机启动、QEMU 冒烟脚本和 CI。

主要交互要求：保留 Rust、VisionFive2/2K1000LA、FAT32 和 FS/VFS 无架构条件编译；不使用 contest-solver；检查所有历史测试分支并选择合适基线；使用现有 gh 授权创建私有仓库并转移到 MindScrath。

验证记录：先运行冒烟脚本，因不存在 ELF 得到预期失败；实现后本地 `make check` 通过格式、clippy、构建和 QEMU 启动检查。测试程序只证明早期 S 模式启动与关机，不证明板上或文件系统功能。官方历史测例未执行，性能实验未执行。初始 main 提交 `46222643e3c2c2e25521684b0d30d37ab20abee6` 的 [GitHub CI](https://github.com/MindScrath/Focos/actions/runs/41846818776) 也已通过。

人工复核责任：团队需阅读并确认启动汇编、链接脚本、unsafe/SBI 调用及所有规格，再在真实板上验证。AI 草拟内容不得直接被描述为经过团队板上测试。各后续 PR 应记录其实际 AI 使用、人工审阅和验证结果。

本次没有复制第三方内核实现；规范、测试清单和参考项目来源见 references.md。会话交互记录保留在用户的 Codex 聊天中；发布前由团队导出与作品相关的记录并去除账户、个人报名和授权信息。
