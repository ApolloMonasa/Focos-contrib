# REGION-001：区域赛交付到什么程度

关联：#8、#10、#12 · 状态：待审；目标按负责人要求调整，能力待实现。

## 交付目标

做成能运行常用 Linux 程序的 Rust 内核：2025 初赛除 LTP 全部通过，vim 能编辑保存，gcc/make 能在 FocOS 内完成构建。真板 FAT32 闭环和缓存实验继续交付。

## 验收范围

| 环境 | 必须完成 |
| --- | --- |
| QEMU RISC-V | 固定 `pre-2025` 的 11 组非 LTP 测试，musl/glibc 两套都运行并通过；保留完整子用例清单 |
| VisionFive2 | 自有 UART/timer/SD；内存、异常、任务和用户态；FAT32 跨簇读写、同步后重启校验；运行下列工具演示 |
| 两个 RISC-V 环境 | vim 编辑保存再打开；gcc 编译、链接并运行新程序；make 完整构建、增量构建和 clean |
| VisionFive2 性能 | FAT32 正确基线与块缓存对照，至少 7 轮配对数据及可重画的图表 |

全套 11 组的区域赛必过环境是 QEMU RISC-V。真板复跑逐项另记；未完成的板上组不能算已通过。LoongArch QEMU 与星云板完整移植仍是全国赛扩展，不声称已达到 2025 双架构官方参赛要求。

## 怎样判完成

- “跑完”须所有纳入的子用例有结果并满足原判据；FAIL、TIMEOUT、NOT_RUN、依赖阻塞都不算完成。11 组 × 2 libc 是 22 个组环境组合，不是 22 个用例。
- 基线为 `pre-2025@8b58dd16d26d30f7c74d48d5832d870d3051b703`，仅排除 LTP；冻结镜像、工具链和 judge 后再冻结子用例分母。
- 测试和工具使用 Ext4 后端；FAT32 基础与优化单独验收。禁止把重打包后的结果称作原镜像兼容。
- vim/gcc 参考 2025 现场镜像的原二进制；`make` 是团队新增验收，版本和来源在接入时锁定。仅输出版本号不算工具可用。
- 保存内核 SHA、镜像/ELF 哈希、命令、串口日志、退出码及文件副作用。gcc 产物须现场新生成；make 修改一个源文件后只重编受影响目标。

## 进阶与限制

2026 CAgent 可在本目标完成后补充；BuildStorm、完整 LTP、双平台及真实磁盘 HNSW 查询放到全国赛。不得用新测例替换未完成的 2025 必达项。

这是团队提高的目标，不是区域赛官方最低要求，也不是按期完成保证。工期检查点见 [路线](../docs/roadmap.md)，来源与适配细节见 [测例审计](../docs/reference/test-audit.md)。
