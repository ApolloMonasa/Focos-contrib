# HAL-001：块设备接口与内存盘


关联：Issue #1

## 要做到什么

对于底层不同硬件，让上层通过统一接口按块读写数据，先用内存盘验证正常读写和错误行为

## 行为约定

- 块大小固定为 512 字节；设备提供总块数 N，有效块编号为 0..N。
- 每次读取或写入一个完整块，调用者提供恰好 512 字节的缓冲区。
- 写入第 0 块后，再读取第 0 块，应得到相同数据；其他块不受影响。
- 缓冲区长度不等于 512 字节，返回缓冲区长度错误。
- 块编号大于或等于 N，返回越界错误。
- 内存盘遇到上述参数错误时，不修改盘内数据或读取目标缓冲区。
- 底层设备读写失败时，接口向调用者返回错误。
- 内存盘由调用者独占使用，本步不处理并发访问。
- `flush` 表示请求同步此前写入；内存盘直接成功，
  只保证数据仍在内存中，不提供断电持久化保证。
- 底层设备不支持同步时，`flush` 返回不支持错误；同步失败时返回设备错误。
## 怎样验收
| 场景 | 操作或测试入口 | 应看到什么 |
|---|---|---|
| 正常读写 | host 测试，待实现：写入第 0 块后读回 | 内容一致，其他块不变 |
| 最后一块 | 读写第 N−1 块 | 成功 |
| 越界 | 访问第 N 块 | 返回越界错误，数据不变 |
| 长度错误 | 使用 511 或 513 字节缓冲区 | 返回长度错误，数据不变 |
| 设备失败 | 使用可注入读写失败的测试设备，待实现 | 错误传递给调用者 |
| 内存盘同步 | 写入后调用 flush，再读回 | 成功且内容一致；不代表断电保存 |
| 不支持同步（unsupported-sync） | host 测试，待实现：使用不支持同步的测试设备，经统一块设备接口调用 `flush` | 调用者收到不支持错误；不得返回成功 |
| 同步失败（failed-sync） | host 测试，待实现：向支持同步的测试设备写入数据，注入同步故障，再经统一块设备接口调用 `flush` | 调用者收到设备错误；不得吞掉错误或返回成功 |
